## :fontawesome-solid-laptop-code: Desarrollo
Este sitio web está desarrollado con las siguientes herramientas y librerías:

- __[MkDocs](https://www.mkdocs.org/){:target="_blank"}__: Generador de sitios web estáticos con Markdown basado en Python.
- __[:simple-materialformkdocs: Material for MkDocs](https://squidfunk.github.io/mkdocs-material/){:target="_blank"}__: Tema para MkDocs.
- __[Python Markdown](https://python-markdown.github.io/){:target="_blank"}__: Procesador de Markdown para Python.
- __[PyMdown Extensions](https://facelessuser.github.io/pymdown-extensions/){:target="_blank"}__: Extensiones para Python Markdown.
- __[Pygments](https://pygments.org/){:target="_blank"}__: Resaltado de sintaxis del código para Python.
- __[:simple-git: Git](https://git-scm.com/){:target="_blank"}__: Sistema de control de versiones.
- __[:simple-github: GitHub](https://github.com/){:target="_blank"}__: Alojamiento del código fuente y la documentación.
- __[:octicons-browser-24: GitHub Pages](https://pages.github.com/){:target="_blank"}__: Servicio de páginas web estáticas de :simple-github: GitHub.
- __[:octicons-play-24: GitHub Actions](https://github.com/features/actions){:target="_blank"}__: Automatización de tareas de :simple-github: GitHub.
- __[Diccionarios](https://github.com/Softcatala/catalan-dict-tools){:target="_blank"} de [:simple-softcatala: Softcatalà](https://www.softcatala.org/){:target="_blank"}__:
    Diccionarios utilizados para la corrección ortográfica de los textos.
- __[PySpelling](https://facelessuser.github.io/pyspelling/){:target="_blank"}__: Corrector ortográfico.
- __[:simple-diagramsdotnet: draw.io](https://app.diagrams.net/){:target="_blank"}__: Web para la creación de diagramas en línea.
